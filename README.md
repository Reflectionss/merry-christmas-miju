# ♥ Merry Christmas, MIJU ♥

미주에게 보내는 크리스마스 코드 아트예요.
글자로 그린 3D 크리스마스트리, 루돌프와 산타 썰매, 불꽃놀이, 한강대교 드론 쇼, 남산타워의 MIJU, 그리고 마지막 편지까지.

## ▶ 바로 보기
**https://reflectionss.github.io/merry-christmas-miju/**

열면 💻 컴퓨터(16:9) / 📱 휴대폰(9:16) 중에서 고를 수 있어요.
휴대폰은 세로로, 밝기를 조금 올려서 보면 더 예뻐요.

## 터미널에서 보기
```
python3 -m pip install --user numpy
python3 tree.py
```
- iTerm2 또는 VS Code 터미널을 권해요 (맥 기본 터미널은 색이 다르게 보일 수 있어요).
- 창 크기: 가로 96칸 × 세로 54줄 이상
- 끝내기: `Ctrl + C`
- 휴대폰 모양으로 보기: `TREE_LAYOUT=phone python3 tree.py` (창 72 × 64 이상)

## HTML 다시 만들기
`tree.py` 의 문구나 색을 바꾼 뒤:
```
python3 tree.py --html index.html
```

Python + numpy 만으로 만들었어요.
